## 怎么申请友链？

想要交换友链的小伙伴们，欢迎发送邮件

```yml
title: 网站名称
description: 一句话介绍下你的网站或者你自己
link: 网站地址
avatar: 头像地址
```

例如我：

```yml
title: 王同学
description: 这在小小角落里，探寻生活的光亮与真知
link: https://wangtopia.top/
avatar: https://img.wangtopia.top/202501/avatar.webp
```
